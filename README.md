# Exploring-Git-Understanding-Open-Source-Through-a-Real-World-Tool
This project explores Git as an open-source tool and tries to understand not just how it works, but why it exists. It looks at the idea of open source, how people collaborate to build software, and how Git fits into that world. Along with the theory, a few simple shell scripts are included to show basic Linux skills in practice.

## Description
This project analyzes Git as an open-source software, including its origin, license, Linux usage, and ecosystem.

## Scripts

### Script 1: System Identity Report
Displays system information like kernel, user, uptime, and Linux distribution.

### Script 2: Package Inspector
Checks if Git is installed and shows version details.

### Script 3: Disk Auditor
Analyzes directory size and permissions.

### Script 4: Log Analyzer
Counts occurrences of keywords in log files.

### Script 5: Manifesto Generator
Creates a personalized open-source philosophy file.
